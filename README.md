# 38-0: unofficial J1 League draft / XI builder

I made a small free browser game for imagining a perfect J.League season.

**38-0** means **38 wins, 0 draws, 0 losses** (38勝0分0敗) over a season — **not** a match score.
You draft / build an XI and play through an imaginary **J1リーグ / Jリーグ** season.

This is a **fan-made, unofficial** project. It is **not** an official Jリーグ product and is **not** affiliated with any club.
